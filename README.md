# 💼 Investment AI Butler — 主後端

多Agent投資AI管家系統

## Agent 架構
- **[A] 數據站** — 自動抓取股價與財報
- **[B] 研究報告推手** — Gemini Deep Research 自動化
- **[C] 價值分析巴菲特蒙格** — 內在價值與安全邊際分析
- **[D] 證券經理人** — 即時買賣訊號
- **[E] 量化效率快篩員** — 第一層股票篩選
- **[F] 數據管理師** — 統一數據管理與計算引擎

## 技術棧
- Python 3.11+
- FastAPI
- PostgreSQL + Redis
- Docker Compose
