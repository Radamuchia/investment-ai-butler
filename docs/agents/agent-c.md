# [C] 價值分析巴菲特蒙格 — Agent 規格文件

> 版本：v0.1.0 | 更新日期：2026-03-30

---

## 職責

依照巴菲特與查理蒙格的投資哲學，對股票進行深度價值分析，輸出投資建議報告。

---

## 分析框架

### 巴菲特指標
| 指標 | 標準 | 說明 |
|------|------|------|
| ROE | > 15% | 股東權益報酬率 |
| ROIC | > 10% | 投入資本報酬率 |
| 自由現金流 | 持續為正 | 企業造血能力 |
| 負債比 | < 50% | 財務健康度 |
| 毛利率 | > 20% | 定價能力 |
| EPS 成長 | 持續增長 | 獲利能力趨勢 |

### 蒙格思維
- 逆向思維：先找出為什麼不該買
- 心理偏誤排除：避免確認偏誤
- 護城河評估：品牌、成本、網路效應、轉換成本

### 內在價值估算
1. **DCF 模型**（折現現金流）
2. **本益比法**（PE Valuation）
3. **股價淨值比法**（PB Valuation）

## 買賣建議評分

| 訊號 | 安全邊際條件 | 說明 |
|------|-------------|------|
| 強烈買入 🟢🟢 | > 30% | 大幅低估 |
| 觀察買入 🟢 | 10% ~ 30% | 合理低估 |
| 持有 ⚪ | -10% ~ 10% | 合理價位 |
| 減碼 🟡 | -10% ~ -30% | 接近高估 |
| 賣出 🔴 | < -30% | 明顯高估或基本面惡化 |
