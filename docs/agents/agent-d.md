# [D] 證券經理人 — Agent 規格文件

> 版本：v0.1.0 | 更新日期：2026-03-30

---

## 職責

整合價值分析結果，判斷進場/出場時機，生成即時買賣訊號並推送通知。

---

## 輸入

| 來源 | 內容 |
|------|------|
| [F] 數據管理師 | [C] 產出的分析建議、即時股價 |

---

## 買賣訊號邏輯

| 訊號 | 條件 | 圖示 |
|------|------|------|
| 強烈買入 | 安全邊際 > 30% | 🟢🟢 |
| 觀察買入 | 安全邊際 10~30% | 🟢 |
| 持有 | 合理價位 | ⚪ |
| 減碼 | 接近合理高點 | 🟡 |
| 賣出 | 超漲 or 基本面惡化 | 🔴 |

---

## 輸出

- 買賣訊號 → [F] 數據管理師
- 即時推播 → WebSocket → [G] UI
- 通知管道：Line Notify / Email / Telegram

---

## 優先權

P1（最高優先）— 訊號延遲不可超過 5 秒
