# [A] 數據站 — Agent 規格文件

> 版本：v0.1.0 | 更新日期：2026-03-30

---

## 職責

自動抓取口袋名單的股價與財報數據，並依智慧排程決定抓取時機。

---

## 輸入

| 來源 | 內容 |
|------|------|
| [F] 數據管理師 | 口袋名單股票代碼清單 |
| 排程觸發 | Cron 定時任務 |
| 事件觸發 | 用戶新增股票至口袋名單 |

---

## 輸出

所有數據統一輸出至 **[F] 數據管理師**，不直接傳遞給其他 Agent。

---

## 智慧抓取時機判斷

| 觸發類型 | 條件 | 說明 |
|----------|------|------|
| 盤前排程 | 每日 08:30（台股）/ 09:00（美股 EST）| 更新前一交易日收盤數據 |
| 盤後排程 | 每日 14:45（台股）/ 16:30（美股 EST）| 更新當日收盤數據 |
| 財報季觸發 | 財報發布日 ± 1 天 | 自動抓取最新財報 |
| 手動觸發 | 用戶加入口袋名單時 | 立即抓取該股票完整數據 |
| 非交易日 | 自動跳過 | 偵測假日與休市日 |

---

## 數據來源 API

| API | 用途 | 數據類型 |
|-----|------|----------|
| Finmind | 台股股價、財報、籌碼 | 台灣上市櫃股票 |
| SEC EDGAR | 美股財報（10-K / 10-Q）| 美國上市公司 |
| FRED | 總體經濟指標 | 利率、CPI、GDP、失業率 |
| TradingView | 技術面數據、圖表數據 | 全球市場 |

---

## 抓取數據清單

### 股價數據
- 開盤價、收盤價、最高價、最低價
- 成交量
- 52 週高低點

### 財報數據
- 損益表：營收、毛利、淨利、EPS
- 資產負債表：總資產、總負債、股東權益
- 現金流量表：營業現金流、自由現金流
- 季報與年報

### 總體經濟
- 聯準會基準利率（FRED）
- CPI 通膨率
- GDP 成長率
- 10 年期美債殖利率

---

## 錯誤處理

- API 限流 → 自動重試（指數退避）
- 數據缺失 → 標記並通知 [F]
- 市場休市 → 跳過並記錄日誌
