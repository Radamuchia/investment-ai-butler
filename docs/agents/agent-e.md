# [E] 量化效率快篩員 — Agent 規格文件

> 版本：v0.1.0 | 更新日期：2026-03-30

---

## 職責

對大範圍股票池進行第一層量化指標快速篩選，輸出符合條件的候選名單至 [A] 進行深度抓取。

---

## 篩選條件（預設模板，用戶可調整）

| 類別 | 指標 | 預設條件 |
|------|------|----------|
| 財務健康 | 負債比 | < 50% |
| 財務健康 | 流動比率 | > 1.5 |
| 獲利能力 | ROE | > 15% |
| 獲利能力 | 毛利率 | > 20% |
| 成長性 | EPS YoY | > 5% |
| 成長性 | 營收 YoY | > 5% |
| 估值 | PE | < 產業均值 |
| 估值 | PB | < 3 |

---

## 輸入

| 來源 | 內容 |
|------|------|
| [F] 數據管理師 | 股票池財務數據矩陣 |
| 用戶設定 | 自訂篩選條件 |

---

## 輸出

- 符合條件的股票清單 → [F] 數據管理師
- [A] 數據站收到後進行深度數據抓取

---

## 批量矩陣查詢

使用 `F.get_matrix()` 一次取得整個股票池的指標矩陣，進行向量化計算，效率最優。
